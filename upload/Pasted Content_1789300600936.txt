# INFRANEX BT — AUTONOMOUS DEVOPS ENGINE

## Master Coding-Agent Implementation Prompt — V2

You are the principal software architect, senior backend engineer, DevOps engineer, cloud infrastructure engineer, Bittensor engineer, and frontend engineer responsible for implementing the **Infranex BT Autonomous DevOps Engine** inside the existing Infranex BT application.

Do not build a toy demo.

Build a production-oriented, modular system that can eventually operate as an autonomous DevOps engineer for Bittensor mining infrastructure.

---

# 1. EXISTING PROJECT

Project name:

**Infranex BT**

Existing frontend:

https://infranex-bt.vercel.app/

The application is intended for personal/solo use initially.

The system's purpose is:

> Discover profitable Bittensor mining opportunities, determine the correct GPU/provider configuration, prepare the infrastructure, deploy the miner, monitor it, automatically recover from failures, and continuously optimize the mining operation.

The application must not assume a fixed investment amount or fixed capital.

All infrastructure economics must be dynamic.

---

# 2. CORE DESIGN PRINCIPLE

Infranex BT must NOT simply:

"Find highest emissions → rent GPU → start miner."

Instead:

"Understand subnet → understand incentive mechanism → understand workload → understand hardware requirements → evaluate GPU/provider economics → validate compatibility → generate deployment plan → obtain approval → provision infrastructure → configure environment → deploy miner → monitor → self-heal → optimize → re-evaluate."

The DevOps Engine must therefore behave like an experienced infrastructure/DevOps engineer.
